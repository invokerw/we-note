## 目标与范围

### 目标

- 重新设计网页端登录页，使登录页具有引导页的完整视觉层次。
- 为 WeNote 设计一套可复用的新品牌图标，并同步到网页端和桌面端登录入口。
- 交付日间与夜间两种可切换的风格方案，保持同一套引导页结构和品牌语言。

### 范围

- 保留现有登录、注册、找回密码、重发验证邮件和邀请链接入口的功能行为。
- 为登录页提供日间和夜间两种可视化风格方案，并使用同一套表单交互。
- 设计新的 WeNote 图标组件，适配浅色、深色和移动端登录布局。
- 复用并更新桌面端登录页的品牌区域和视觉样式。
- 补充可访问名称、键盘焦点、移动端布局和构建验收。

### 明确排除

- 不修改认证 API、注册策略、会话存储和账户操作逻辑。
- 不改动登录后的笔记库工作区视觉体系。

## 验收条件

- [ ] 登录页保留邮箱、密码、登录、注册切换、找回密码和重发验证邮件入口，成功登录流程不变。
- [ ] 页面提供日间和夜间两种可切换的登录页视觉风格，用户可以通过入口直接对比。
- [ ] 新图标在网页端和桌面端品牌区域可见，浅色、深色和移动端下保持清晰。
- [ ] 登录页在窄屏下不出现横向溢出，表单控件和焦点状态可操作。
- [ ] `npm run build --prefix apps/web` 通过，且桌面模式构建通过。
- [ ] 任务分支完成自审、`git diff --check` 和受影响测试记录。

## 实现计划

1. 将认证品牌区域抽成可复用的新图标与两套风格配置，覆盖网页端和桌面端。
2. 将登录页改造成可切换的日间和夜间预览，保留现有认证请求和交互。
3. 优化两套主题的对比度、标题换行、卡片层次和响应式表现，运行构建和预览入口验收。
4. 自审本轮差异并提交任务分支，交付用户选择后继续收敛。
