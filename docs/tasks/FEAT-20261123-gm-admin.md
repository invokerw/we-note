## 用户原始需求

需要一个 GM 网页管理整个服务端，包括用户管理、禁用注册和邮箱绑定、邀请注册、SMTP 邮件配置、修改密码、附件管理和存储占用等笔记应用管理能力。

已确认的产品决策如下。

- 面向自托管、多用户服务实例。
- 管理员默认只查看元数据，正文访问需要临时授权并记录审计。
- 默认仅邀请注册，并且必须验证邮箱。
- SMTP 通过 GM 页面维护。
- 备份和恢复进入第一版 GM。

## 自托管验收步骤

1. 进入 `http://localhost:18080/gm`，输入服务器初始化令牌、管理员邮箱与密码。部署时也可以通过 `WENOTE_SETUP_TOKEN` 指定初始化令牌。
2. 在「系统设置」保存 SMTP 配置，发送测试邮件。在「操作记录」查看收件人和结果。生产部署将 `-public-url` 配为用户可访问的 HTTPS 地址。`-mail-url` 可单独指定邮件链接的地址。本地启动脚本使用验收实例端口。
3. 在「邀请」发邮件，使用另一个浏览器会话打开邀请链接，设置密码后查收验证邮件。默认仅允许受邀用户开户，完成邮箱验证后才能登录。升级前已有账号可用登录页的「重发验证邮件」完成验证。
4. 在「用户」发起密码重置，或撤销会话、禁用和恢复账号。用户可在笔记页的账户入口修改自己的密码。
5. 在「附件与存储」查看各用户附件的名称、笔记库和大小，可以移入回收站或恢复。去重后的 Blob 大小、当前笔记、历史版本、附件是不同统计口径。后台只展示管理元数据。
6. 在「存储配置」分别选择在线笔记与附件和备份目标。在「备份」创建并校验备份，点击「恢复备份」并核对时间。确认后会先创建「恢复前自动备份」。恢复完成后用所选备份中的管理员密码登录，可选择该自动备份撤回恢复。自动备份在「系统设置 → 备份计划」配置。

邮件收发验收使用本机测试 SMTP。公网服务商送达率、S3 部署、大数据量恢复与切换生产实例未做实机验收。自动化恢复验收覆盖普通笔记正文及附件原始字节；未完成的上传不属于已提交的笔记内容。
