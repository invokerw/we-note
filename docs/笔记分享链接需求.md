# 笔记分享链接

需求已验收 · 2026-11-25

## 分享一篇笔记

发送者在笔记上点击「分享」，系统为当前已保存的版本生成一个可复制的完整 URL。发送者可以直接把链接发给任何人，生成链接时无需填写接收账号、密码或配置下载权限。

接收者在手机或电脑浏览器打开有效链接，直接看到笔记标题和只读内容。Markdown 按阅读模式展示，正文中属于分享快照的图片随正文加载。对于暂时无法在线预览的格式，页面显示文件名、预览提示和文件操作。

## 阅读页上的两个操作

| 按钮 | 点击后的结果 |
| --- | --- |
| 保存到我的笔记 | 已登录的接收者选择自己的目标笔记库和目录，保存一份可独立编辑的副本。未登录时，点击才提示登录，登录成功后接着保存当前笔记。保存成功后可以打开副本，其中引用的 WeNote 图片和附件也归入接收者的笔记库。 |
| 下载源文件 | 接收者无需登录即可下载分享时的原文件。单篇笔记沿用原文件名、扩展名和文件内容，例如分享 `会议记录.md` 就下载 `会议记录.md`。 |

新建分享在有效期内可以重复下载和保存。个人设置按笔记本列出有效分享，显示文档名称和有效期，可在列表中停止分享。

沿用现有的快照规则。发送者之后修改原笔记，链接仍展示分享时的版本。发送者撤销分享后，链接上的阅读、保存和下载均失效，接收者此前已保存的副本仍可使用。已有受密码或权限限制的链接继续执行创建时的限制。

## 验收场景

1. 分享一篇带图片的 Markdown 笔记，复制 URL 到未登录的浏览器。首次打开就能读到正文和图片，并看到「保存到我的笔记」和「下载源文件」。
2. 在同一浏览器点「下载源文件」，核对下载文件的名称、后缀和字节内容与分享版本一致。
3. 未登录时点「保存到我的笔记」，登录另一个账号并保存。打开副本后能看到图片、修改正文，发送者的原笔记仍保留原内容。
4. 发送者撤销分享，再次打开原 URL 会看到分享已失效的提示。接收者仍能从自己的笔记库打开此前保存的副本和图片。
