# 个人设置与侧栏入口

需求已验收 · 2026-11-25

## 从头像进入设置

点击工作区左上角的头像，直接弹出「个人设置」。桌面弹窗左侧列分类，右侧默认显示「账户与安全」，顶部显示当前邮箱。头像按钮支持键盘操作，悬停或读屏时提示「打开个人设置」。关闭或按 Esc 回到原笔记，保留草稿、光标和滚动位置。修改密码、退出或返回同步涉及离开编辑器时，沿用草稿离开确认。

手机在笔记列表顶栏左侧放头像，右侧打开笔记库目录。点击头像打开设置分类列表，点分类进入详情，返回时逐级退回。阅读和编辑正文时把顶栏空间留给文件操作。

| 设置项 | 用户可以做什么 |
| --- | --- |
| 账户与安全 | 更换或恢复头像，查看当前登录邮箱，修改密码，查看自己的账户活动（现有审计日志）。退出登录单独放在本页底部。 |
| 编辑与插件 | 首屏提供正文字号、默认 Markdown 打开模式和记忆上次模式。分屏滚动、保存时格式化、XMind 主题在对应编辑器设置中展开。插件的安装、启停与配置沿用现有插件管理及偏好存储。 |
| 我的分享 | 选择笔记库，查看自己创建的链接。默认选中当前库；每条以笔记名或原分享范围为标题，显示状态和有效期，支持撤销。撤销前显示对象名，说明已保存的副本可继续使用。 |
| 导出 | 从当前库创建导出任务，选择仅笔记或完整库，下载在线或离线便携 ZIP。关闭设置后回到原草稿。 |
| 设备与同步 | 桌面和 Android 接入现有同步页，管理本地目录、同步选项和已注册设备。离线打开本地库时仍能调编辑偏好，头像标明本地使用状态。 |

管理员在设置分类底部多一个「服务端管理」入口，进入已有管理后台。各端按已接入的能力显示设置项。普通工作区沿用现有浅色设计，字号复用编辑器偏好。

## 头像与密码

「账户与安全」顶部并排显示头像和登录邮箱。点击「更换头像」，从设备选择图片并预览，点「保存」后，设置页和左上角同时显示新头像。取消选择或上传失败时保留原头像，失败时可重新选择或重试。点「恢复默认头像」并确认后，两个位置都恢复默认图标。

头像归当前账号。切换笔记库、刷新或在另一台设备登录同一账号后，都能看到已保存的头像。切换账号时显示对应账号的头像。离线本地库仍能从头像进入编辑偏好，更换头像和修改密码需联网并登录。

点「修改密码」后输入当前密码、新密码和确认密码。新密码至少 8 位，两次输入须一致。当前密码错误或新密码未通过校验时，在表单内提示原因并允许重试。如果还有未保存的笔记，先完成草稿离开确认，再提交改密。成功后提示「密码已修改，请重新登录」，沿用现有会话撤销规则，所有设备需用新密码重新登录。

## 左下角按钮的去向

| 当前入口 | 建议位置 | 原因 |
| --- | --- | --- |
| 修改密码、退出登录、审计日志、服务端管理 | 头像 → 个人设置 | 都与当前身份有关，切换笔记库时仍需可用。 |
| 插件、返回同步 | 头像 → 编辑与插件、设备与同步 | 插件用于配置编辑环境；返回同步用于管理当前设备。 |
| 搜索 | 第二栏「全部笔记」顶部的搜索框 | 直接输入关键词即可按文件名、目录路径和已保存的正文搜索，结果显示在同一列表。可重用或清空最近搜索，在所选目录和当前库的全部笔记之间切换。 |
| 本地端的「笔记」 | 合并到已有「全部笔记」或手机底栏「笔记」 | 两处都用于返回文件列表。 |
| 回收站 | 左侧目录树下方的独立导航项 | 从当前库直接查看和恢复已删除的笔记。手机从笔记列表右上角打开目录。 |
| 导出 | 头像 → 导出 | 在设置中显示当前笔记库，创建并下载导出文件。 |
| 库工具、加密笔记库、批量分享 | 下线 | 保留历史密文，已有分享链接继续按原权限访问。 |
| 分享快照 | 移除左下角按钮；笔记标题栏放「分享」，手机放在正文「更多」中 | 打开哪篇就分享哪篇，省去输入路径和邮箱。Android 原有系统文本分享在支持的文件上明确标作「系统分享」。 |
| 分享管理 | 头像 → 我的分享 | 创建链接在笔记上完成，集中管理只负责查找和撤销。 |
| 收件箱、已发送 | 下线这两项功能及对应页面 | 用户复制分享链接后自行发送，接收者直接打开链接。 |
| 三栏、双栏、单栏布局 | 保留在左下角 | 写作时可以直接切换布局。 |

## 分享切换条件

单篇链接需求已验收，左下角入口的调整以新版分享在相应客户端可用为前提。用户从笔记上生成当前**已保存版本**的完整 URL，提供复制操作。有草稿时提示「将分享上次保存的版本」，可选择先保存再分享。接收者打开链接即可阅读，阅读页提供「保存到我的笔记」和「下载源文件」。登录提示在保存时出现。分享快照、图片、原文件下载和历史链接权限遵循[笔记分享链接需求](笔记分享链接需求.md)。

新版单篇分享和链接撤销入口可用后，撤下旧的常驻按钮，同时移除按接收者邮箱发送快照的流程。新分享仅支持单篇已保存的笔记，自动附带其引用的图片。

## 验收场景

1. 在有未保存文字的笔记中打开头像、查看账户活动、关闭弹窗。回到同一篇笔记，草稿和编辑位置仍在。手机系统返回先关闭设置详情。
2. 用普通账号和管理员账号分别打开设置，只有管理员能进入服务端管理。在没有普通库的账户中也能修改密码和退出。
3. 在「编辑与插件」修改正文字号，返回 Markdown 笔记确认生效。离线本地客户端也能打开可用偏好。
4. 从一篇笔记生成链接，在未登录窗口打开并下载同名源文件；点击保存才进入登录流程。发送者从「我的分享」选中正确的库和记录，撤销后原链接失效。
5. 分别登录新账号和有过收发记录的账号，确认侧栏和个人设置均无「收件箱」「已发送」或历史收发入口。此前已保存的副本仍可从笔记库打开，已有受限链接继续执行原权限。
6. 在账户 A 预览一张图片后取消，原头像仍在。重新选择并保存，核对左上角和设置页，再切库、刷新并从另一设备登录 A。各处显示同一头像。切换到账户 B 后看到 B 自己的头像。回到 A 恢复默认，刷新后仍显示默认图标。
7. 输入错误的当前密码或两次不同的新密码，确认可以纠正后重试。带草稿提交改密时取消离开，确认草稿仍在且原密码可用。保存笔记后完成改密，在两台已登录设备核对重新登录要求，验证新密码可用、旧密码失效。
8. Web 宽屏工作区左下角只显示布局切换。能从第二栏搜索到正文中含关键词的笔记，从文件夹树下方找到回收站，从头像设置导出当前笔记库。目录和多篇笔记无法新建分享链接。
