# 笔记加星与快速访问

需求已验收 · 2026-11-25

## 从左栏打开常用笔记

在左侧栏「我的文件夹」正上方增加常驻入口「加星」，配星形图标。点击后，左栏选中「加星」，中间栏标题显示「加星」，汇总当前用户在当前笔记库各个文件夹中加过星的笔记。点击其中一篇，右侧打开原笔记。同一篇笔记在列表中只出现一次，同名笔记可通过所在路径区分。

加星列表为空时，入口仍可点击，中间栏提示「还没有加星的笔记」，并引导用户右键笔记或点击笔记右上角的星形按钮。

## 加星与取消加星

| 操作位置 | 用户操作与结果 |
| --- | --- |
| 中间栏的笔记行 | 右键点击目标笔记，未加星时菜单显示「加星」，已加星时显示「取消加星」。操作作用于被右键点击的那一行，即使右侧正打开另一篇笔记。 |
| 中间栏的「加星」列表 | 右键笔记并选择「取消加星」，该行立即移出列表。用户仍可从原文件夹打开这篇笔记。取消最后一篇时显示空列表提示。 |
| 右侧笔记标题栏 | 在右上角常驻一个星形按钮。空心星表示可以「加星」，实心星表示可以「取消加星」。单击即可切换，悬停提示和读屏名称显示当前可以执行的操作。 |

同一篇笔记的右键菜单、标题栏星形和加星列表随操作一起更新。即使在「加星」列表中取消了正在编辑的笔记，右侧也继续显示该笔记，保留草稿和光标位置。用户刷新或重新打开该库后，仍能看到上次保存的加星状态。

## 验收场景

1. 在尚未给任何笔记加星的库中，点击「我的文件夹」上方的「加星」，核对选中状态、中间栏标题和空列表提示。
2. 打开笔记 A，在中间栏右键另一文件夹中的笔记 B 并选择「加星」。A 的星形仍为空心。从左栏进入「加星」，能看到 B，点开后标题栏显示实心星，正文与原笔记一致。
3. 在 B 的正文输入一段草稿，点击右上角实心星。B 从加星列表消失，草稿仍可继续编辑。再次点击空心星，B 重新出现在列表，右键菜单显示「取消加星」。
4. 在「加星」列表右键 B 并取消加星，核对空列表提示及标题栏空心星。回到 B 的原文件夹，确认能打开 B，右键菜单显示「加星」。
5. 在两个文件夹中各给一篇同名笔记加星，刷新后按路径分别打开。取消其中一篇，重新打开该库后，列表只保留另一篇。切换笔记库时，列表显示所选库的加星笔记。
